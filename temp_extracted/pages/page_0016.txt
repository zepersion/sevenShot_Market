4.4 取消订单
项目 内容
接口 POST /api/order/cancel/{id}
鉴权 是
描述 买家取消待支付订单
请求参数：
字段 类型 必填 描述
reason String 是 取消原因
4.5 支付订单
项目 内容
接口 POST /api/order/pay/{id}
鉴权 是
描述 模拟支付（面试项目可简化）
请求参数：
字段 类型 必填 描述
payType Integer 是 支付方式：1微信 2支付宝 3余额
真实项目：调用微信/支付宝支付API，支付回调异步通知。
面试项目：模拟支付，直接修改订单状态为待发货。
